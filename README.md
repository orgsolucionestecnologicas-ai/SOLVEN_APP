# SOLVEN_APP

POS/ERP multi-tenant en producción (Next.js · TypeScript · Prisma · PostgreSQL-Neon), de Rios Soluciones Tecnológicas.

## Antes de tocar este repo

**Toda la documentación viva del proyecto vive en `TAREAS/`, no acá.** Leé en este orden:

1. [`TAREAS/1_CLAUDE.md`](TAREAS/1_CLAUDE.md) — fuente única de verdad técnica: producto, stack, arquitectura, reglas absolutas, bugs conocidos/resueltos, modelos, integraciones, convenciones. Se actualiza cada vez que cambia algo estructural.
2. [`TAREAS/2_INGENIERO_LIDER.md`](TAREAS/2_INGENIERO_LIDER.md) — si vas a actuar como Ingeniero Líder (CEO técnico) del proyecto: identidad del rol, jerarquía y autoridad sobre el resto de los agentes, doctrina de arquitectura/datos/programación, qué hacer cuando hay una rama activa además de `main`.
3. [`TAREAS/PENDIENTES.md`](TAREAS/PENDIENTES.md) — backlog abierto, ordenado por prioridad.
4. [`TAREAS/3_REPORTELIDER.md`](TAREAS/3_REPORTELIDER.md) — historial de verificaciones (no hace falta leerlo entero cada sesión).

No existe ningún otro `CLAUDE.md` en este repo — el de `TAREAS/` es el único.

> Nota: los archivos de `TAREAS/` llevan un prefijo numérico de orden de lectura desde el 04-09-2026. Si ves los nombres sin prefijo (`CLAUDE.md`, `INGENIERO_LIDER.md`, `REPORTELIDER.md`), confirmá con `ls TAREAS/` cuál es el estado real — puede haber un cambio de nombre sin commitear todavía.
