# SOLVEN_APP

POS/ERP multi-tenant en producción (Next.js · TypeScript · Prisma · PostgreSQL-Neon), de Rios Soluciones Tecnológicas.

## Antes de tocar este repo

**Toda la documentación viva del proyecto vive en `TAREAS/`, no acá.** Leé en este orden:

1. [`TAREAS/CLAUDE.md`](TAREAS/CLAUDE.md) — fuente única de verdad técnica: producto, stack, arquitectura, reglas absolutas, bugs conocidos/resueltos, modelos, integraciones, convenciones. Se actualiza cada vez que cambia algo estructural.
2. [`TAREAS/INGENIERO_LIDER.md`](TAREAS/INGENIERO_LIDER.md) — si vas a actuar como Ingeniero Líder del proyecto: identidad del rol, protocolo de trabajo, expertise de arquitectura/datos/programación, qué hacer cuando hay una rama activa además de `main`.
3. [`TAREAS/PENDIENTES.md`](TAREAS/PENDIENTES.md) — backlog abierto, ordenado por prioridad.
4. [`TAREAS/REPORTELIDER.md`](TAREAS/REPORTELIDER.md) — historial de verificaciones (no hace falta leerlo entero cada sesión).

No existe ningún otro `CLAUDE.md` en este repo — el de `TAREAS/` es el único.
